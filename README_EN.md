# Jupiter - English README

This repository contains small network utilities (netcat-style client/server and TCP flag scanning) intended for security testing in controlled environments.

Important: These tools are offensive/network testing utilities. Use them only on networks and systems where you have explicit authorization.

Quick actions in this change:
- Standardized runtime messages and logs to English.
- Fixed minor bugs and improved robustness (streaming uploads, safer argument parsing, added missing imports).

Usage
------
See the tool CLI help for each tool, for example:

python3 net/netcat.py -h
python3 -m jupiter (if the console is configured)
